# Политика источников

Проект — инструмент мониторинга и каталогизации, а не поставщик
телевизионных услуг. Успешный HTTP-ответ не считается доказательством
воспроизводимости и не даёт права на переиспользование контента.

## Правила включения источников

1. Для каждого источника ведётся запись в реестре (ниже) и в
   `config/sources.yaml`.
2. Источник подключается адаптером; все записи наследуют `source_id`
   (принцип source-first).
3. Политика публикации (`public_policy`):
   - `allow` — потоки могут попадать в публичные сборки (лицензия явно
     разрешает переиспользование);
   - `review` — публикация только после подтверждения `stream_id` в
     `data/state/approved_streams.yaml`;
   - `deny` — никогда не публиковать (собственные/неясные списки).
4. Источники с неясными правами **не включаются** в публичные сборки до
   проверки.
5. Секретные URL (токены, ключи, креды) не публикуются независимо от
   политики источника.

## Реестр источников

Заполняется при подключении/проверке каждого источника:

| Поле | Значение |
|------|----------|
| id | `iptv-org-ru` |
| URL | `https://iptv-org.github.io/iptv/countries/ru.m3u` |
| Тип данных | M3U-плейлист публично доступных каналов |
| Лицензия/условия | данные сообщества iptv-org; проверить перед включением `public_policy: allow` |
| Переиспользование | TBD |
| Включение в публичный плейлист | `review` |
| Дата последней проверки условий | — |

| Поле | Значение |
|------|----------|
| id | `free-tv` |
| URL | `https://github.com/Free-TV/IPTV` |
| Тип данных | M3U-плейлист |
| Лицензия/условия | TBD |
| Переиспользование | TBD |
| Включение в публичный плейлист | `review` (источник выключен до проверки) |
| Дата последней проверки условий | — |

Аналогичные записи обязательны для EPG-источников (`config/epg_sources.yaml`)
и источников логотипов (`config/logo_sources.yaml`): лицензия гайдов и
изображений не переиспользуется автоматически.

## Чек-лист проверки нового источника

- [ ] Актуален ли URL и стабилен ли формат (адаптер + фикстура в тестах)?
- [ ] Какая лицензия/условия у данных? Разрешено ли переиспользование?
- [ ] Есть ли в потоках токены/приватные адреса?
- [ ] Не является ли источник зеркалом платных каналов без прав?
- [ ] Заполнена ли запись в реестре и дата проверки?

## Что проект не принимает

- Потоки, обходящие DRM, авторизацию или платные подписки.
- Поиск и распространение нелегальных копий платных каналов.
- Изменения, публикующие источники с неясными правами без записи в реестре.
